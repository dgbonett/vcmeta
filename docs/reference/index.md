# Package index

## Meta-analysis

  : Confidence interval for an average G-index agreement coefficient
- [`meta.ave.cor.gen()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.cor.gen.md)
  : Confidence interval for an average correlation of any type

  : Confidence interval for an average effect size using a constant
  coefficient model
- [`meta.ave.gen.log()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.gen.log.md)
  : Exponentiated confidence interval for an average of log-transformed
  parameters
- [`meta.ave.gen.rc()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.gen.rc.md)
  : Confidence interval for an average effect size using a random
  coefficient model
- [`meta.ave.gen()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.gen.md)
  : Confidence interval for an average of any parameter
- [`meta.ave.mean.ps()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.mean.ps.md)

- [`meta.ave.mean2()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.mean2.md)

- [`meta.ave.meanratio2()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.meanratio2.md)

  : Confidence interval for average odds ratio from 2-group studies
- [`meta.ave.path()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.path.md)

  : Forest plot for average effect sizes
- [`meta.ave.prop.ps()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.prop.ps.md)
  : Confidence interval for an average proportion difference in

- [`meta.ave.prop2()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.prop2.md)
  : Confidence interval for an average proportion difference in 2-group

  : Confidence interval for an average proportion ratio from 2-group

- [`meta.ave.semipart()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.semipart.md)
  : Confidence interval for an average semipartial correlation
- [`meta.ave.slope()`](https://dgbonett.github.io/vcmeta/reference/meta.ave.slope.md)
  : Confidence interval for an average slope coefficient

## Standard errors

Standard errors for various effects

- [`se.agree()`](https://dgbonett.github.io/vcmeta/reference/se.agree.md)
  : Computes the estimate and standard error for a G-index of agreement
- [`se.ave.cor.nonover()`](https://dgbonett.github.io/vcmeta/reference/se.ave.cor.nonover.md)
  : Computes the standard error for the average of two Pearson
  correlations with no variables in common that have been estimated from
  the same sample
- [`se.ave.cor.over()`](https://dgbonett.github.io/vcmeta/reference/se.ave.cor.over.md)
  : Computes the standard error for the average of two Pearson
  correlations with one variable in common that have been estimated from
  the same sample
- [`se.ave.mean2.dep()`](https://dgbonett.github.io/vcmeta/reference/se.ave.mean2.dep.md)

  differences from two parallel measurement response variables in the

## Miscellaneous

Additional functions

- [`cor.from.t()`](https://dgbonett.github.io/vcmeta/reference/cor.from.t.md)
  : Computes a Pearson correlation between paired measurements from a
  paired-samples t statistic
- [`meta.chitest()`](https://dgbonett.github.io/vcmeta/reference/meta.chitest.md)
  : Computes a chi-square test of effect-size homogeneity
- [`stdmean2.from.t()`](https://dgbonett.github.io/vcmeta/reference/stdmean2.from.t.md)
  : Computes Cohen's d from pooled-variance t statistic
- [`table.from.odds()`](https://dgbonett.github.io/vcmeta/reference/table.from.odds.md)
  : Computes the cell frequencies in a 2x2 table using the marginal
  proportions and odds ratio
- [`table.from.phi()`](https://dgbonett.github.io/vcmeta/reference/table.from.phi.md)
  : Computes the cell frequencies in a 2x2 table using the marginal
  proportions and phi correlation
